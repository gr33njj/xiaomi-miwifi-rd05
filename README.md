#Xiaomi MiWiFi RD05
Переход с CN версии на Global 

## Usage
1. Сбросить настройки роутера, пройти первоначальную настройку и установить пароль. Отключите всё лишнее от роутера и от ПК. По WiFi шить на свой страх и риск.

2. Запустите !START.bat, выберите пункт 2. Следуйте указаниям в окне.

3. Выберите 4, в папке backups будет создан бэкап вашей прошивки. Сохраните его в надежном месте.

4. Выберите 7 для установки Глобальной прошивки, следуйте указаниям в окне. Через ~2-3 минуты прошивка будет установлена, можно заходить на роутер: 192.168.31.1 - для глобальной прошивки.
